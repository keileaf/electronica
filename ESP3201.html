ESP3201: Gráfico de Puntos en Processing

Processing IDE (Java Puro)
Lienzo de Dibujo en Pantalla (Canvas & Osciloscopio)

En esta práctica comprenderás cómo construir un monitor gráfico en tiempo real tipo osciloscopio: el eje horizontal X avanza píxel a píxel mediante una variable acumuladora (contador), mientras el eje vertical Y mapea la magnitud de señales generadas al azar o recibidas por sensores.

Eje X: contador + 50 (Avance horizontal) Eje Y: (X × 0.2932) + 200 (Escalado de señal) Borrador: if (contador > 500) { contador = 0; }
Diagrama de Coordenadas
Canvas: 800 x 600 px
Desglose de Operaciones y Variables
Término Valor / Rango Fórmula / Origen Función Visual
Regla de Tres del Escalado: La caja mide 300 píxeles de alto y el dato máximo es 1023. Al dividir 300 ÷ 1023 = 0.2932, cualquier número cabe perfectamente dentro del marco sin salirse.
Simulador Didáctico: ¿Cómo se mueve y limpia la pantalla?
Avanza paso a paso para ver cómo cambian las coordenadas y cuándo se activa el borrador if.
1
El Avance (Eje X)

La variable contador suma +1 en cada turno. Mueve los puntos hacia la derecha:

X = contador + 50
2
La Altura (Eje Y)

La variable X1 es un número de 0 a 1023. Lo adaptamos multiplicando por 0.2932:

Y = (X1 × 0.2932) + 200
3
El Borrador (if)

Cuando contador > 500, pinta un rectángulo gris encima y reinicia a 0:

if (contador > 500) { contador = 0; }
Inicio (X = 0) Paso actual: 0 de 500 Límite (X = 500)
0
Instrucción: point(50, 200);
Dibujando punto...
El contador aún no llega a 500. El punto se dibuja y se avanza hacia la derecha.
